# AgentDesk — Releases

Bu depo yalnızca **AgentDesk** masaüstü uygulamasının yayın paketlerini barındırır (kurulum dosyaları, güncelleme manifesti ve imza dosyaları). Kaynak kod bu depoda değildir.

- Güncelleme kanalı: **stable** (tek kanal).
- Kurulum imzasızdır; Windows SmartScreen "bilinmeyen yayıncı" uyarısı gösterebilir (Daha fazla bilgi → Yine de çalıştır). Paket bütünlüğü uygulama içinde Ed25519 imzalı manifest ile doğrulanır.
- Önceki sürüm yerelde saklanır; sorun olursa uygulama içinden önceki sürüme dönülebilir.

Yayınlar: **Releases** sekmesi.
